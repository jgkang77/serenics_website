# SERENICS website

Static HTML, CSS, and minimal JavaScript. No dependencies, build step, backend, analytics, or external fonts.

Serve this directory using any static web server, for example `python -m http.server 8000 --bind 127.0.0.1`, then open http://127.0.0.1:8000.

Deploy the contents of this directory to any static website host. The master sheet is intentionally excluded from the public directory.

All images and WAV files are byte-for-byte copies of the supplied assets. The official logo includes its original symbol, wordmark, and tagline. Technical images have not been redrawn or modified. Some source figures have low pixel dimensions; the page provides scrolling and original-asset links without inventing additional detail.

Content source: SERENICS_Company Website_Master_Sheet.pptx and the supplied implementation brief. Publication information is transcribed from slide 8 without added links. All five reported performance values are reproduced as supplied.
